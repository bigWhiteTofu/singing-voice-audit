# Supplementary Materials

Materials accompanying *Candidate Eligibility and Selection Consequences in Singing-Voice Quality Evaluation: A Generated-Score Audit*.

[Download supplementary.zip](https://github.com/bigWhiteTofu/singing-voice-audit/releases/download/materials/supplementary.zip) (62.49 MB).

## Contents

| File | Contents |
| --- | --- |
| `supplement.pdf` | Supplementary methods, definitions, figures, and numerical tables. |
| `analysis.zip` | Candidate eligibility, selection, expansion, and score diagnostics; machine-readable results, analysis scripts, and supplementary LaTeX sources. |
| `code.zip` | Neural reference implementation, preprocessing and evaluation routines, configurations, and dependency files. |
| `data.zip` | Reference scores, prediction arrays, and record and system metadata. |
| `README.txt` | File inventory and usage instructions. |

## Usage

1. Download and extract `supplementary.zip`.
2. Open `supplement.pdf` with a PDF reader.
3. Extract the component ZIP files while preserving their directory structures.
4. Follow `README.md` inside `analysis.zip` and the supplied dependency files for the numerical analyses.
5. Supplementary LaTeX sources are in `04_Supplementary/` inside `analysis.zip`; figure assets are in `02_Figures/`.
